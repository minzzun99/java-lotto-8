# 로또

---

## 프로그램 동작 순서

1. 구입 금액을 입력받기 위한 안내 메시지를 출력한다.
    - `구입금액을 입력해 주세요.`
2. 구입금액을 입력받는다.
    - 구입 금액은 1,000원 단위로 입력받으며 1,000원으로 나누어떨어지지 않는 경우 예외 처리
3. 발행한 로또 수량 및 번호를 출력한다.
    -  ```
       8개를 구매했습니다.
       [8, 21, 23, 41, 42, 43]
       [3, 5, 11, 16, 32, 38]
       [7, 11, 16, 35, 36, 44]
       [1, 8, 11, 31, 41, 42]
       [13, 14, 16, 38, 42, 45]
       [7, 11, 30, 40, 42, 43]
       [2, 13, 22, 32, 38, 45]
       [1, 3, 5, 14, 22, 45]
       ```
    - 1,000원당 1개 / 로또 번호 오름차순 정렬
4. 당첨 번호를 입력받기 위한 안내 메시지를 출력한다.
    - `당첨 번호를 입력해 주세요.`
5. 당첨 번호를 입력받는다.
6. 보너스 번호를 입력받기 위한 안내 메시지를 출력한다.
   - `보너스 번호를 입력해 주세요.`
7. 보너스 번호를 입력받는다.
8. 당첨 통계를 출력한다.
   - ```
     당첨 통계
     ---
     3개 일치 (5,000원) - 1개
     4개 일치 (50,000원) - 0개
     5개 일치 (1,500,000원) - 0개
     5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
     6개 일치 (2,000,000,000원) - 0개
     총 수익률은 62.5%입니다.
     ```
---

## 기능 목록

### 입출력

- [X] 사용자 입력을 위한 안내 메시지 출력
    - [X] `구입금액을 입력해 주세요.`
    - [X] `당첨 번호를 입력해 주세요.`
    - [X] `보너스 번호를 입력해 주세요.`
- [X] 사용자를 통한 입력
    - [X] 구입금액 입력 (1,000원 단위)
    - [X] 당첨 번호 입력 (1 ~ 45)
    - [X] 보너스 번호 입력 (1 ~ 45)
    - [X] `camp.nextstep.edu.missionutils.Console`의 `readLine()`을 활용
- [X] 결과 확인을 위한 출력
    - [X] 구매한 로또 개수 출력
    - [X] 로또 번호 출력
    - [X] 당첨 통계 출력
      - 1등: 6개 번호 일치 / 2,000,000,000원
      - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
      - 3등: 5개 번호 일치 / 1,500,000원
      - 4등: 4개 번호 일치 / 50,000원
      - 5등: 3개 번호 일치 / 5,000원

### 로또 구매

- [X] 입력받은 금액에서 구매 가능한 로또 개수 계산
- [X] 입력된 문자열 정수형 변환
- [X] 로또 구매 금액은 1,000원 단위로 입력 받고 1,000원으로 나누어 떨어지지 않는 경우 예외 처리
- [X] 로또 구매 금액은 100,000원까지 가능
- [X] 입력 받은 금액 내에 `,` 제거 기능 (ex. `10,000` 으로 입력한 경우)

### 로또 발행

- [X] 구매한 로또 개수 만큼 로또 발행
- [X] 1 ~ 45 사이의 숫자 중 중복되지 않은 6개의 숫자 랜덤 발행
- [X] `camp.nextstep.edu.missionutils.Randoms`의 `pickUniqueNumbersInRange()`를 활용

### 당첨 번호 입력

- [X] 1 ~ 45 사이의 숫자 중 중복되지 않은 6개의 숫자 입력

### 보너스 번호 입력

- [X] 1 ~ 45 사이의 숫자 중 당첨 번호와 중복되지 않은 1개의 숫자 입력

### 당첨 통계 출력

- [X] 5등 이상 당첨 내역 출력
- [X] 총 당첨 금액 출력
- [X] 총 수익률 계산 (소수점 둘째 자리에서 반올림)

---

## 예외 처리

사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후<br>"[ERROR]"로 시작하는 에러 메시지 출력 후 에러 발생 지점 부터 재입력

### 예외 발생 상황

- [X] 로또 구입 금액이 1,000으로 나누어 떨어지지 않는 경우
- [X] 로또 구입 금액이 1,000 이하인 경우
- [X] 숫자가 아닌 문자가 입력된 경우
- [X] 구입 금액이 100,000원을 초과한 금액이 입력된 경우 (로또 1인 1회차 구입 가능 금액 100,000원)
- [X] 입력된 값이 없는 경우
- [X] `null` 값이 입력된 경우
- [X] 당첨 번호 입력 시 중복된 숫자를 입력한 경우
- [X] 보너스 번호 입력 시 당첨 번호와 중복된 숫자를 입력한 경우
- [X] 당첨 번호 및 보너스 번호 입력 시 1 ~ 45 범위를 벗어난 숫자를 입력한 경우
